Split character frames
======================

The original combined sprite sheet stays in this folder. Split images are saved in
one folder per character, then one folder per motion:

<character>/<motion>/row_<01|02>_frame_<01...>.png

Characters: blade, lance, oracle, titan, warden, seer, wisp, reaver
Motions: idle, walk, attack, hurt, death

The source sheet has two unlabeled frame rows per character. They are named row_01
and row_02 because the sheet does not identify them as directions.
